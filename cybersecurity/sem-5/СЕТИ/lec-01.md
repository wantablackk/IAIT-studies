# Как построить интернет. 08.09.2026

## Устройства

**Типы:**
- **Оконечные устройства** (компьютеры, ноутбуки, смартфоны и т. д.)
- **Устройства инфраструктуры сети:**
  - маршрутизатор / router;
  - коммутатор / switch;
  - концентратор / хаб / hub / мультиплексор;
  - межсетевой экран / брандмауэр / firewall (IPS/IDS);
  - патч-панель.

**Канал связи:**
- Передатчик
- Приёмник
- Линия связи:
  - Медный провод (коаксиальный / coaxial, витая пара (UTP, STP категорий 1–7), телефонная линия);
  - Оптоволокно (одномодовое, многомодовое);
  - Радиоканал;
  - Лазерный / оптический канал.

## Эталонная и историческая многоуровневые модели взаимодействия открытых систем

1. **TCP/IP**
2. **OSI**

### Уровни моделей

**TCP/IP:**
1. Прикладной (приложений)
2. Транспортный
3. Межсетевой (сетевой)
4. Сетевого доступа (канальный / физический)

**OSI:**
1. Прикладной
2. Представления
3. Сеансовый
4. Транспортный
5. Сетевой
6. Канальный
7. Физический
