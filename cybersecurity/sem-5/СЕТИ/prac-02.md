# Cisco. 18.09.2026

Устройства Cisco имеют несколько режимов (уровней) настройки:

- **Пользовательский режим (user mode);** `Switch>`
  - `ip a` — просмотреть IP-адрес устройства
  - `ping <ip>` — проверить связь с узлом
  - `traceroute <ip>` — трассировка маршрута
  - `enable` — перейти в привилегированный режим
- **Привилегированный режим (privileged mode);** `Switch#`
  - `disable` — выйти обратно в пользовательский режим
  - `show clock` — посмотреть время
  - `clock set` — установить время
  - `show running-config` — просмотреть текущие (изменённые) настройки
  - `show startup-config` — просмотреть изначальные/сохранённые настройки
  - `configure terminal` — перейти в режим глобальной конфигурации (alias `conf t`)
- **Режим глобальной конфигурации (global configuration mode);** `Switch(config)#`
  - `exit` — выйти обратно в привилегированный режим
  - `hostname <name>` — поменять имя устройства в сети
  - `banner motd #text#` — изменить баннер (сообщение дня)
  - `enable secret <password>` — установить пароль для перехода в привилегированный режим
- **Линия консоли (`line con 0`)**
  - `login <логин>`
  - `password <пароль>`
  - `exit` — выйти из настройки консольного порта
- **Линии VTY (`line vty 0 4`)**
  - `login <логин>`
  - `password <пароль>`
  - `exit` — выйти из настройки VTY-линий

### Основные команды Cisco:

- `Switch(config)# username <имя> secret <пароль>` — создание локальной базы пользователей.
- `Switch(config-line)# login local` — привязать авторизацию через локальную базу пользователей к линии.
- Установка IP-адреса на коммутатор/маршрутизатор:
	```
	Switch(config)# interface vlan 1
	Switch(config-if)# ip address  <маска>
	Switch(config-if)# no shutdown
	```
- Чтобы выключить: `Switch(config-if)# shutdown`
- `Switch# show mac address-table` — показать таблицу коммутации (примечание: можно использовать ключевое слово `do`, чтобы выполнять команды привилегированного режима из режима конфигурации, а-ля `sudo`).
