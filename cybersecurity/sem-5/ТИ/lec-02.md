# Меры информации и их классификация. Понятие энтропии. 07.09.2026

## Основные меры информации

В зависимости от направлений исследований в теории информации различают следующие её меры:
- структурные;
- синтаксические;
- семантические;
- прагматические.

### Прагматическая мера

Определяет полезность и ценность информации для достижения пользователем поставленной цели (ёмкость памяти, производительность ПК, скорость передачи информации).

### Семантическая мера

Основывается на понятии содержательности информации, единицей измерения которой является **тезаурус** (совокупность сведений, которыми располагает пользователь или система).

### Структурная мера

Определяется подходом к оценке особенностей структуры сообщений. Среди структурных мер различают:
- **Геометрическая:** $M = m_x \cdot m_t \cdot m_n$
- **Комбинаторная:** $Q_{p\text{п}} = h^l$
  - Количество информации в комбинаторной мере вычисляется как количество комбинаций элементов.
  - С помощью комбинаторных мер оценке подвергается комбинаторное свойство потенциального структурного разнообразия информационных комплексов.
  - Комбинирование элементов в информационных комплексах базируется на основных понятиях комбинаторики (сочетания, перестановки, размещения):
    - **Сочетания без повторений:** $Q_c = \frac{h!}{l!(h - l)!}$
    - **Сочетания с повторениями:** $Q_{c\text{п}} = \frac{(h + l - 1)!}{l!(h - 1)!}$
    - **Перестановки без повторений:** $Q_n = h!$
    - **Перестановки с повторениями:** $Q_{n\text{п}} = \frac{(a + b + \dots)!}{a! \cdot b! \cdots}$
    - **Размещения с повторениями:** $Q_{p\text{п}} = h^l$
    - **Размещения без повторений:** $Q_p = \frac{h!}{(h - l)!}$
- **Аддитивная мера Хартли:** для практического удобства использования меры информации Ральф Хартли ввёл аддитивную меру, позволяющую вычислять количество информации в двоичных единицах - битах:
  $$I_x = \log_2(h^l) = l \cdot \log_2(h)$$

### Синтаксическая мера

Определяется вероятностными характеристиками элементов сообщения. Поэтому её чаще называют **статистической мерой**.

Информация и вероятность события находятся в обратно пропорциональной зависимости:
$$I = \frac{1}{P}$$
где $I$ - информационная ёмкость, $P$ - вероятность сообщения.

Частые (ожидаемые) события несут мало информации, а редкие события, наоборот, обладают высоким информационным содержанием.

## Энтропия

1. Если вероятности событий одинаковы (равновероятные события), то энтропия равна:
   $$H = \log_2(n)$$
2. Если вероятности событий различны, то энтропия определяется формулой Шеннона:
   $$H = -\sum_{i=1}^{n} p_i \log_2(p_i)$$
   - $H$ - энтропия источника сообщений;
   - $n$ - количество возможных состояний (символов алфавита);
   - $p_i$ - вероятность появления $i$-го символа/события.

---

Простейший дискретный источник сообщений $X$ в каждый фиксированный момент времени выдаёт некоторый символ $x_i$ из конечного алфавита $X = \{x_1, x_2, x_3, \dots\}$ с вероятностью $p(x_i) = p_i$.

**Аксиома 1:** Информация одиночного события $I(x_i)$ ($x_i \in X$), появляющегося с некоторой вероятностью $P_i$, имеет неотрицательное значение:
$$I(x_i) \ge 0$$

**Аксиома 2:** Если имеют место два независимых события $x_i$ и $y_j$ ($x_i \in X, y_j \in Y$), то для них справедлива совместная вероятность:
$$P(x_i, y_j) = P(x_i) \cdot P(y_j) = p_i \cdot p_j$$

**Аксиома 3:** Количество информации является непрерывной функцией от вероятности.

- **Аксиомы 1 и 2** показывают, что информация нескольких событий не может взаимно уничтожаться.
- **Аксиома 3** показывает, что любые, сколь угодно малые изменения вероятности приводят к изменению количества информации.

Из Аксиомы 3 следует, что количество информации можно описать как:
$$I(p) = -\log_2(p)$$

Клод Шеннон предположил, что прирост информации равен устранённой неопределённости.

**Информационная энтропия** - мера неопределённости некоторой системы (в статистической физике или теории информации), в частности, непредсказуемость появления какого-либо символа первичного алфавита.

**Энтропия по Шеннону** является разностью между информацией, содержащейся в сообщении, и той частью информации, которая точно известна (или хорошо предсказуема) в сообщении.

**Энтропия по Хартли** - количество бит, которое необходимо для передачи одного сообщения от источника к приёмнику, а количество информации - общее количество бит, необходимое для передачи всего сообщения.

### Свойства энтропии

1. Энтропия всегда неотрицательна:
   $$H(X) = -\sum_{i=1}^{k} p_i \log_2(p_i) \ge 0$$
   при $0 \le p_i \le 1$ и $\sum_{i=1}^{k} p_i = 1$.

2. Энтропия равна 0 в том крайнем случае, когда вероятность одного из событий равна 1, а остальных - 0:
   $$H(X) = 0 \quad \text{при} \quad p_i = 1$$

3. Энтропия сообщения максимальна, когда события источника или элементы сообщения равновероятны:
   $$H_0 = \log_2(k)$$
   где $H_0$ - информационная ёмкость, $k$ - количество элементов.
   - Это свойство определяет совпадение мер информации по Шеннону и по Хартли.
   - Это свойство определяет потенциальную ёмкость сообщения или источника.
   - В случае неравновероятного источника количество информации по Шеннону всегда меньше потенциальной информационной ёмкости.

4. Энтропия обладает свойством **аддитивности**. Если два дискретных источника заданы объединённой вероятностной схемой $C = A \cdot B$, где:
   $$A = \{a_i, p(a_i)\}, \quad B = \{b_j, p(b_j)\}, \quad C = \{c_{ij}, p(c_{ij})\}$$
   причём $p(c_{ij}) = p(a_i, b_j) = p(a_i) \cdot p(b_j)$, тогда по определению энтропии для этого источника:
   $$
   H(C) = -\sum_{i=1}^{N}\sum_{j=1}^{M} p(a_i, b_j) \log_2 p(a_i, b_j) =
   \sum_{i=1}^{N}\sum_{j=1}^{M} p(a_i, b_j) \log_2 \frac{1}{p(a_i)} + \sum_{i=1}^{N}\sum_{j=1}^{M} p(a_i, b_j) \log_2 \frac{1}{p(b_j)} =
   H(A) + H(B)
   $$
   Аддитивное свойство: $H(C) = H(A) + H(B)$.

   Для непрерывного распределения дифференциальная энтропия имеет вид:
   $$H(Y) = -\int_{-\infty}^{+\infty} p(y) \log_2 p(y) \, dy$$

### Аксиомы Хинчина и Фадеева

- Пустое сообщение не содержит информации.
- Количество информации, содержащейся в сообщении, пропорционально его длине.

То есть для реализации сообщения $T$ в рамках алфавита $A$ объёмом $n$ символов алфавита, где $l$ - длина $T$:
$$l(T) = l \cdot l_i$$

#### Аксиомы Фаддеева:
1. $H(p, 1 - p)$ непрерывна при условиях $0 \le p \le 1$ и не положительна хотя бы в одной точке.
2. Энтропия вероятностной схемы симметрична относительно $p_i$.
3. При $n \ge 2$:
   $$H(p_1, \dots, p_n, q_1, q_2) = H(p_1, \dots, p_n) + p_n \cdot H\left(\frac{q_1}{p_n}, \frac{q_2}{p_n}\right)$$
   где $p_n = q_1 + q_2$.

#### Аксиомы Хинчина:
1. Энтропия конечной вероятностной схемы ненулевая и непрерывная по вероятности $p_i$ при условиях: $0 \le p_i \le 1$, $\sum_{i} p_i = 1$.
2. Энтропия, заданная конечной вероятностной схемой, симметрична по $p_i$.
3. Энтропия вероятностной схемы, в которой есть нулевой элемент, равна энтропии схемы без этого элемента.
4. Энтропия объединённой вероятностной схемы равна сумме энтропий:
   $$H(q_{11}, q_{12}, \dots, q_{nm}) = H(p_1, \dots, p_n) + H_P(Q)$$
5. Энтропия конечной вероятностной схемы максимальна при равновероятных событиях:
   $$H(p_1, \dots, p_n) \le H\left(\frac{1}{n}, \dots, \frac{1}{n}\right) = \log_2(n)$$
