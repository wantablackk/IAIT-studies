# Организация управления задачами. 14.09.2026

При создании ОС используется двухуровневая (иногда трёхуровневая) схема планирования:
- **Уровень внешнего планирования** — выполняет действия, относительно редкие в системе, но требующие больших системных затрат.
- **Уровень внутреннего планирования** — выполняет частые и более короткие действия по управлению процессами.

Объектом управления являются процессы, которые выступают как конкурирующие друг с другом потребители ресурсов.

## Средства и механизмы управления задачами

Информация, передаваемая ОС пакетом заданий, записывается по определённым правилам. Они представлены описаниями языков. Примером являются язык пакетных файлов в MS-DOS, JCL в ОС ЕС. Обработка JCL-операторов выполняется JCL-процессорами.

Два принципа реализации JCL-процессоров:
- **Компиляционный принцип:** предусматривает наличие в ОС компиляторов с языка управления заданиями. Сначала операторы компилируются, а затем могут использоваться для управления процессами обработки данных.
- **Интерпретационный принцип:** требует наличия Shell-программы (утилиты), воспринимающей операторы командного языка.

## Функции элементов планировщика задач

- **Системный ввод:** считывание управляющих операторов пакетов заданий с устройств системного ввода, их анализ и формирование управляющих таблиц.
- **Инициатор:** ...
- **Терминатор:** ...
- **Системный вывод:** вывод выходных наборов данных и системных сообщений.

Программы системного ввода формируют управляющие таблицы. Совокупность управляющих таблиц образует БД управляющей информации, необходимой для осуществления процессов долгосрочного и краткосрочного планирования в ОС. Связь таблиц этой БД осуществляется с помощью ключевых полей, в которые заносятся ссылки на записи в этой же или другой таблице.

### Средства управления задачами на уровне внутреннего планирования
Инициатор передаёт управление супервизору процессов, который распределяет ресурсы и координирует развитие всех процессов, находящихся в системе. Управление осуществляется с помощью внутреннего планирования, цель которого — организация оптимальной обработки задач в рабочей смеси.

**Рабочая смесь** — совокупность задач, одновременно находящихся на обслуживании ОС. С каждой задачей связаны программы-модули.

### Различия модулей:
- **По структуре:**
  - модуль простой структуры;
  - модуль оверлейной структуры;
  - модуль динамической структуры.
- **По использованию:**
  - однократно используемые;
  - многократно используемые;
  - реентерабельные.

### Системы управления процессами должны выполнять следующие операции:
- создание процесса;
- уничтожение процесса;
- приостановление процесса;
- возобновление процесса;
- изменение приоритета процесса.
